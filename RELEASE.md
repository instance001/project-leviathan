# Project Leviathan Public Specification Release

## Release Marker

This repository marks the public release of the Project Leviathan architecture
specification set.

The purpose of this release is to place the documents into the commons as
AGPLv3-governed reference material before any prototype or implementation work
is built in separate repositories.

## Repository Scope

This release is document-only.

It does not include source code, prototypes, model weights, datasets, hosted
services, package artifacts, or executable applications.

Future implementations may cite, derive from, or test these specifications, but
they should be developed in their own repositories.
